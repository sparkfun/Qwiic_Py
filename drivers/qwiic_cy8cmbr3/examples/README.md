# Sparkfun CY8CMBR3 Examples Reference
Below is a brief summary of each of the example programs included in this repository. To report a bug in any of these examples or to request a new feature or example [submit an issue in our GitHub issues.](https://github.com/sparkfun/Qwiic_Py/issues). 

NOTE: Any numbering of examples is to retain consistency with the Arduino library from which this was ported. 

## Qwiic Cy8Cmbr3 Ex1 Basic
`qwiic_cy8cmbr3_ex1_basic.py`

Shows how to set up and use the Qwiic CY8CMBR3 Capacitive Soil Moisture Sensor
 for basic soil moisture readings.

## Qwiic Cy8Cmbr3 Ex2 Advanced
`qwiic_cy8cmbr3_ex2_advanced.py`

Shows how to set up and use the Qwiic CY8CMBR3 Capacitive Soil Moisture Sensor
 for advanced soil moisture readings including settings.

## Qwiic Cy8Cmbr3 Ex3 Led
`qwiic_cy8cmbr3_ex3_led.py`

Shows how to set up and use the Qwiic CY8CMBR3 Capacitive Soil Moisture Sensor
 for LED control based on soil moisture readings.

## Qwiic Cy8Cmbr3 Ex4 I2C Addr
`qwiic_cy8cmbr3_ex4_i2c_addr.py`

Shows how to change the I2C address of the Qwiic CY8CMBR3 Capacitive Soil Moisture Sensor

## Qwiic Cy8Cmbr3 Ex5 Multi
`qwiic_cy8cmbr3_ex5_multi.py`

Shows how to interact with multiple Qwiic CY8CMBR3 Capacitive Soil Moisture Sensors

## Qwiic Cy8Cmbr3 Ex6 Set Range
`qwiic_cy8cmbr3_ex6_set_range.py`

Shows how to set up and use the Qwiic CY8CMBR3 Capacitive Soil Moisture Sensor
 for reading of raw counts with range setting options.
